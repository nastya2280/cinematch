# cinematch
App for choosing movie 
1. Название проекта
«Синемэтч» — сервис для подбора фильма одному человеку или группе людей.

2. Проблема
Людям часто сложно выбрать фильм для совместного просмотра, потому что у участников
разные предпочтения по жанрам, рейтингу, году выпуска и длительности фильма.

3. Цель
Создать сервис, который помогает одному пользователю или группе быстро подобрать
подходящие фильмы на основе их предпочтений.

4. Пользователи
Отдельные пользователи, компании друзей, пары и семьи.

5. Источники данных
Внешний API с информацией о фильмах, TMDB (The Movie Database).

6. Обработка данных
Система получает данные, проверяет их, сохраняет в базу, фильтрует фильмы, сравнивает
их с предпочтениями пользователей и сортирует по степени соответствия.
Если пользователей несколько, система учитывает предпочтения всех и показывает фильмы, которые лучше всего подходят группе.
Пример: один пользователь хочет комедию, другой — фантастику. Система ищет
фильмы, которые максимально подходят обоим.

7. Хранение
Данные сохраняются в базе данных PostgreSQL.

8. Выход / результат
Пользователь получает на сайте список фильмов, которые подходят его требованиям или
требованиям всей группы.

9. Основные функции первой версии
1. Загрузка фильмов из API.
2. Сохранение фильмов в базу данных.
3. Поиск фильмов по жанру.
4. Фильтрация по характеристикам.
5. Сохранение предпочтений пользователя.
6. Учёт предпочтений нескольких пользователей.
7. Вывод списка наиболее подходящих фильмов.

10. Границы проекта
В первую версию входят загрузка и хранение данных о фильмах, фильтрация, ввод пользовательских предпочтений, совместный подбор и вывод результатов.
В первой версии не реализуются:
 нейросети;
 машинное обучение;
 мобильное приложение;
 просмотр фильмов внутри сервиса;
 оплата;
 сложная регистрация.
